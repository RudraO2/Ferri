  This is a board game night. Players move between tables; hosts run games and teach them. Point players looking for a game to the tables desk, and anything left behind to lost and found.
tasks:
  - List the games people are bringing and who hosts each table
  - Plan the table layout and the number of seats
  - Import the RSVP list for check-in
  - Set up a lost and found spot at the venue
---
The desks a board game night runs on: a tables desk where hosts post their games and free seats, a check-in desk for the door, and lost and found for the dice bags and water bottles left behind.

# Bring your own accounts

Only an Anthropic API key is needed for the [Quick start](../README.md#quick-start). Every other row is optional: it says what it turns on and which guide sets it up. Values go in `.env`; after you change them, restart Ferri and Desk with `docker compose restart ferri desk`. `./ferri doctor` shows each part as on, off or broken.

Mattermost needs no account: it runs inside the stack.

- Name each platform's bot or app Switch, not Ferri. Slack and Discord turn a typed `@ferri` into a mention of a bot whose name starts with "ferri", and that message never reaches Ferri ([platforms.md](platforms.md)).
- The Builder's values (OpenAI, the site's Resend key, Supabase, Vercel, Luma) are copied into the Builder's own files. After you change one, run `pnpm builder:setup` again on the Builder's machine, then restart `pnpm builder:controller`.
- `.env` is in `.gitignore`. Keep every key there, never in a commit or a chat.
- Menu paths as of November 2026.
